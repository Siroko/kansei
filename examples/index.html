Examples

Small scenes from the TypeScript version of Kansei. Each one needs a browser with WebGPU. The sources are in examples/ on GitHub.

  • Path-traced GICornell box with hybrid path-traced global illumination
  • GI and particlesPath-traced Cornell box with compute trail particles
  • Particle simulationCornell box particles with post-processing
  • Voxel tracerA voxelised Cornell box, ray traced
  • Post-processingBloom, depth of field, volumetric fog and colour grading
  • Curl volumetricScrolling terrain with curl-noise particles
  • FluidGPU particle fluid
  • Fluid textFluid particles that form letters
  • ComputeCompute-shader particles (the old home page)
  • FloraCompute-driven instanced geometry
  • RendererTextured meshes with SSAO
  • MSDF textSigned-distance-field text, animated by compute
  • Video textureA video mapped onto geometry

The newer Rust/WASM examples live in rust/kansei-wasm/examples; build one with wasm-pack to run it.
